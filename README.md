# u

A minimal, colorful and sleek terminal file manager.

```
 u — keybindings

╭──────────────────────────────────────────────────────╮
│  NAVIGATION              SELECTION                   │
│  j / ↓   move down       space   toggle mark         │
│  k / ↑   move up         x       cut selection       │
│  h / ←   parent dir      y       copy selection      │
│  l / →   open             p       paste here         │
╰──────────────────────────────────────────────────────╯
```

## Installation
 
**Quick install (recommended):**
 
```bash
curl -fsSL https://raw.githubusercontent.com/ufuayk/u/linux/install.sh | bash
```
  
**Manual install (not recommended):**
 
```bash
chmod +x u.rb
sudo mv u.rb /usr/local/bin/u
```
 
Either way, run `u` from anywhere once it's installed.
